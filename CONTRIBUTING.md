# Contributing

Submit code changes and issues to [https://github.com/JACKT72xp/architecture-actions-public](https://github.com/JACKT72xp/architecture-actions-public).
Change `actions/arc42-tqi/` there. Maintainers review, merge and test changes
upstream before synchronizing this repository. Direct analyzer changes here
will fail the source verification check and can be overwritten by synchronization.

Distribution workflow changes also belong upstream, under `distribution/arc42-tqi/`.

[Upstream contribution guide](https://github.com/JACKT72xp/architecture-actions-public/blob/main/actions/arc42-tqi/CONTRIBUTING.md).
